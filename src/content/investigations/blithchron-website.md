## Starting from an open-source foundation

The Blithchron 2027 website builds on open-source code by Bruno Simon. That is an important part of the project's provenance, and I want to credit it directly. The site was an adaptation of that foundation for Blithchron, not an implementation created from a blank slate.

## Architecture as part of the contribution

Using an existing codebase did not settle how the Blithchron site should be put together. I made major architecture decisions while adapting the project, shaping the structure that the festival website would use. Those decisions were a substantial part of my work as a Design and Tech Coordinator, alongside taking the site through deployment on 5 August 2026.

The distinction matters to me: crediting the original open-source work and recognizing my own architectural contribution are both necessary for an accurate account of the project.
